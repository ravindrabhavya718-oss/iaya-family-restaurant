## ✨ Features & Architecture

* **Hero Section:** High-impact South Indian culinary visuals, verified rating badge (★ 4.0 | 3,483+ Reviews), bilingual branding, and direct CTAs.
* **About Section:** Rich identity showcasing heritage vegetarian flavours, comfortable ambience, and family dining.
* **Signature Favourites:** Interactive showcase cards for South Indian Thali, Masala Dosa, Traditional Tiffins, Veg Meals, Grape Juice, and Filter Coffee.
* **Thali Spotlight:** Special dedicated section celebrating Kakinada's favourite vegetarian thali.
* **Drinks Spotlight ("Complete Your Meal"):** Highlight on customer-favourite **Signature Grape Juice** and **South Indian Filter Coffee**.
* **Interactive Menu:** Live real-time dish search, category filter tabs (*Tiffins, Meals & Thalis, Rice & Mains, Beverages*), and download menu modal.
* **Customer Reviews:** Dynamic animated stat counters and verified customer review quotes.
* **Photo Gallery & Lightbox:** Filterable masonry gallery with an accessible full-screen photo lightbox viewer (with keyboard & touch navigation).
* **Location & Map:** Embedded Google Map, one-click directions, and address copy utility.
* **Opening Hours & Weekly Schedule:** Live open/closed badge and weekly operating hours modal.
* **Mobile-First UX:** Touch-friendly buttons, slide-out hamburger navigation, and a floating bottom action bar (*Call Now* & *Directions*).
* **SEO Optimized:** Semantic HTML5, descriptive meta tags, Open Graph cards, and Schema.org `Restaurant` JSON-LD structured data.

## 🚀 How to Run Locally

You don't need any build tools or external dependencies. Simply open `index.html` in any browser or run a lightweight local server:

### Using Python:
```bash
python -m http.server 8080
```
Open [http://localhost:8080](http://localhost:8080) in your browser.
